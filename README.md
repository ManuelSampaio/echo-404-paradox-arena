# ECHO//404 v14.0.2

Created & developed by **MANUEL SAMPAIO01**.

The main entry highlights ORIGIN, the vertical platform mission, with three selectable operators and a five-step playable control simulation before each run. Mobile has explicit one-tap short/high jump buttons; keyboard retains variable jump height. All operators share the same physics and hitboxes. Choice uses `echo404_origin_operator`, independently of classic saves. The station and operator art are regenerated by `scripts/create-operator-art.cjs`.

The alternate mode is a futuristic temporal puzzle game: record your path, rewind and cooperate with up to three past versions of yourself. There are 25 authored arenas with different walls, routes, sensors, gates and backgrounds. The first five teach the echo mechanic; robots, drones and sentinels progressively introduce detection, pursuit, aimed shots and echo decoys. Later puzzles add portals, timed gates and ordered signals.

Controls: WASD/arrows to move, E/Shift to record and rewind, Backspace to undo the latest echo, Space for a short protective phase, Escape to pause. Touch uses a directional pad and actions on opposite sides. Portrait view transposes the board and movement axes while keeping characters upright. Completion and help use compact cards.

## v14.0.2 controls and playability validation

Phase protection lasts 0.40 seconds with a 1.8-second recovery. The HUD shows its remaining recovery and the actual number/order of sequence signals. Changing arena clears old notifications. `tests/paradox-combat.cjs` completes all 25 arenas without disabling threats or injecting completed traces.

## Modes and saves

- `index.html` / `paradox.html`: v14, 25 arenas, separate `echo404_v14` medals and records, daily shareable challenge, optional offline installation.
- `classic.html`: original classic game, unchanged.
- `campaign-v12.html`: previous campaign hub, including ORIGIN REBORN and missions 02–06. Older versions remain accessible through its archive.

No save migration or clearing is performed. Existing classic and campaign keys are neither written nor removed by v14. Saves remain local to this browser/device. The practice simulation does not advance mission time, award medals or write completion flags. Challenges share a seed/link, not a global leaderboard. Only v14 resources are handled by its service worker; older games retain their own loading behavior. Gameplay scripts and styles check the network first and fall back to the offline cache; original art and the pinned engine use cached resources.

## Implementation

`paradox-data.js` contains authored layouts and difficulty. `paradox-core.js` is the deterministic collision, replay, puzzle, security and save model. `paradox-game.js` presents it using the locally vendored Phaser 3.90.0 (MIT); it does not use Arcade physics. The human and patrol sprite sheets are original repository assets. `scripts/create-paradox-art.cjs` regenerates the 25 backgrounds and icons. Arena textures load on demand; offline installation caches all arenas. No API key, external runtime CDN or build step is required.

For a real-browser portrait/landscape viewport review, open `tests/mobile-preview.html`; it embeds the actual game at 390×844 or 844×390 without changing gameplay state. This checks responsive layout, not device hardware.

The temporal suite solves all 25 authored puzzles through actual collision, replay, portals, timed gates and ordered signals with patrols/hazards disabled to isolate puzzle feasibility. Security tests separately check all patrol configurations, robot/drone/sentinel detection, pursuit, telegraphed shots, cover, decoys and recovery. The Phaser suite boots the real engine, renders all arenas, and checks controls, pause, menu, completion/next and portrait projection. Web tests check navigation, home progress, cache scope and offline fallback. The full-threat suite additionally completes all 25 arenas through legal movement, phase, waiting and recording, with enemies and hazards active and zero failures. This is a deterministic automated playthrough, not a human difficulty review or a physical iPhone test.

Created & developed by **MANUEL SAMPAIO01**.

## Run locally

Serve the repository with any static web server, for example:

```sh
python -m http.server 8000
```

Open `http://localhost:8000/`. Use left/right and up/space to move/jump, E to record an echo, or the two-hand touch controls.

## Verification

Dependency-free checks (Node.js):

```sh
node tests/navigation.cjs
node tests/worlds.cjs
```

Checks cover syntax/links, save preservation, both modes, mission completion/retry, actual echo gate physics, NULL overload, relays, ARCA ordering/timeout, patrol detection/chase/search, cover, damage, timed hazards, safe spawn and reachable platform geometry.

For real Canvas rendering checks, optionally install `@napi-rs/canvas` in your development environment and run:

Progress remains in this browser's localStorage under the existing keys. No save migration or reset is required. Continue opens the next unfinished mission from its beginning; in-mission checkpoint positions are not saved between visits.

## v12.0 — ORIGIN REBORN pilot

`origin-reborn.html` is the new mission 01 and the first Phaser mission. Missions 02–06 keep their previous engine for now. `origin-v97.html` remains in the archive, and `classic.html` is unchanged.

The new authored map climbs from a ruined dock through a switchback silo, an echo-powered crane and upper rooftops. Movement has acceleration/braking, variable-height jumps, jump buffering, coyote time and a short dash. A recorded echo replays once and holds its final pose; keeping it on the anchor powers the moving crane. Three required fragments lead to evacuation, with three optional memories, checkpoint recovery and bronze/silver/gold runs. Both the new pilot and the older missions use smaller completion cards with optional story details.

The pilot uses the locally vendored **Phaser 3.90.0** distribution (MIT, `vendor/PHASER-LICENSE.md`). All images are served from this repository. No API key, runtime CDN or build step is needed. The original completion/result keys remain compatible, and completing the pilot cannot downgrade a previously saved gold medal or best time.

New source files:

- `origin-pilot-data.js`: map, replay interpolation, medal rules and compatible save handling.
- `origin-pilot.js`: Phaser scene, Arcade movement/collisions, echo crane, controls, audio and patrols.
- `origin-pilot.css`: responsive gameplay UI and compact notifications.
- `scripts/create-origin-art.cjs`: reproducible explorer/patrol sprite sheets, terrain and backdrop.

For the real Phaser physics and Canvas rendering checks:

```sh
npm ci
npm test
npm run test:phaser
# Optional: export an actual Phaser-rendered frame.
RENDER=/tmp/origin-reborn.png npm run test:phaser
```

The Phaser suite uses a DOM adapter and predecoded local art while running the actual Arcade solver. It checks every authored jump, the optional rooftop route, echo recording, crane carrying, movement, pause, recovery and victory. It is not a physical iPhone test or a browser asset-loader test.
