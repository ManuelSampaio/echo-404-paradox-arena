# ECHO//404 v4.0 — Visual upgrade

- All ten levels retain their original gameplay and now include additional environmental storytelling: containment doors, warning strips, escaped-subject silhouettes, archive consoles, dimensional debris, and structural fractures.
- PixiJS remains the world renderer. GSAP animates the lighting layer. Optional bloom is limited to the lighting layer on desktop, and skipped on mobile or reduced-motion devices.
- The existing mobile menu CSS was preserved.
- The current game is a top-down temporal puzzle game. Jumping, gravity, enemy AI, and secret-room collision logic are **not** included in this visual-only safe update. They require a deliberate gameplay redesign to avoid breaking echo replay and level solutions.
- Check the browser console for CDN loading failures; optional effects fail gracefully.
- Credits preserved.
